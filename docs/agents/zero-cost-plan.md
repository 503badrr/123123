# Zero-Cost Operating Plan

الهدف: عدم اضافة تكلفة بنية جديدة مع الالتزام بحدود الخطط المجانية الحالية.

- اعادة استخدام GitHub الحالي بدلا من CI مكرر في GitLab.
- اعادة استخدام Supabase الحالي وعدم انشاء مشروع او branch مدفوع.
- عدم ادخال Convex في production ما دام Supabase يغطي الحاجة.
- اعادة استخدام Cloudflare Worker الحالي وعدم انشاء deployment stack ثان.
- استخدام Zid/Salla/Shopify عبر التكاملات الحالية/التجريبية فقط؛ اي رسوم تجارية او اشتراك خارجي ليست ضمن ضمان الصفر.
- Creative workflows تعمل عند توفر رصيد/خطة مجانية؛ لا تجعلها dependency للاطلاق.

اي خطوة قد تنشئ موردا مدفوعا تتوقف قبل التنفيذ وتطلب موافقة المالك.
